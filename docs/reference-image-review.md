## Privacy, rights and quality

REF-01 contains sample professional details inappropriate for redistribution. Reference boards are internal, excluded from public Git and all application output. Their possession establishes design intent, not a redistribution licence. None is licensed here for public reuse, traced as an illustration, or extracted into icons. REF-02/03 also contain platform and laptop marks; author generic native icons and object silhouettes in Phase 3. The small embedded mockups are inspiration, not source screenshots.

The portrait candidate was opened at display size and in a native source-pixel crop beside the old derivative. It depicts the same person as the existing public avatar, but only the owner can approve the final selection. No generated or stock person is allowed. The frame image must use `object-fit: contain` initially, with focal point 50% 38%; a square crop requires a separate owner review.

## Exact design disposition

The latest written Phase 2.1 request outranks all board annotations. REF-02 controls home composition; REF-01 controls detailed content surfaces; REF-03 controls clarified functional behaviour and album intent. Existing token and layout specifications supply measurable values. This review resolves routine composition differences; it does not approve factual sample text or pending media publication.

No source identifies exactly two additional work/copy objects beyond the existing labelled book spines and record actions. The boards show Notes, Ideas and Builds as examples, not verified new content. Omit unidentified controls. If the owner still wants two additional controls, the only missing input is their labels or intended destinations; this is optional and does not block Phase 3.
